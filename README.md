# Delta

The most optimal approach to data in your apps.

The main parts of **Delta** are:
- [deltaflow](https://github.com/Azarattum/Delta/tree/main/packages/deltaflow): A conflict-free replicated incremental streaming pipeline for your data.
- [deltaquery](https://github.com/Azarattum/Delta/tree/main/packages/deltaquery): A query language compiler for deltaflow.
